# Needy Augmentation

A modded module for Keep Talking and Nobody Explodes, made to be a utility to balance needy modules.

Created using:
- The [community fork of KTaNE Modkit](https://github.com/Qkrisi/ktanemodkit)
- ModConfig script by samfundev
